# Orange 2025 rates
- TACD lists rates by AUTHORITY/FUND only (3 blocks: block 1 = 2025 final, matching Table 1 adopted, e.g. Apopka 4.4376, Belle Isle 4.7845, Ocoee 4.95; block 2 = proposed; block 3 = rolled-back). No district->authority composition is printed, so every total is a SUM OF AUTHORITIES with the composition inferred.
- Countywide: county 4.4347 + school 6.449 (fund 2: 3.201, fund 3: 3.248). Library 0.3748 everywhere except Winter Park/Maitland (own libraries). Sheriff MSTU 1.8043 and Fire MSTU 2.8437 for ORG (unincorporated) codes only: Table 1 levies imply a 123.5B base for both, = sum of 2026-roll taxable value of all ORG* codes (124.7B), so no city code pays them. City codes add city operating (+ WP debt 0.2062, Maitland debt 0.196 as listed under the city authority; separate authority lines show 0.2207/0.202). Bay Lake/LBV add CFTOD 8.5836 + 3.84 debt.
- WMD inferred (diff only 0.0508): SFWMD for suffix 10/26/35/75/70 and codes mostly in T24S or T23S-R28E (Kissimmee basin), else SJRWMD. ORG10 vs ORG11 (and ORL26 vs ORL08) look like SFWMD/SJRWMD splits of the same area.
- Dependent districts matched by comparing Table 1 levy/millage bases with each code's taxable value in the 2026 NAL plus township/range: Lake Conway -> suffix 20 (BI20+EDG20+ORG20 = 1.62B vs 1.58B), Windermere W&N -> suffix 75 (9.0B vs 8.8B), Big Sand Lake -> ORG37, Lake Holden -> ORG82, Lake Pickett -> ORG45 (medium). Small lake MSTUs, downtown/I-Drive levies are best guesses (low) and many small 23S/29E codes may carry an unidentified OBT/OCP/Jessamine levy (low; listed in note).
- Main codes (ORG11, ORG10, ORL08, ORG35, APK11, ORL26, ORG65, OCO65, WG65, WP06, MTL06) have no dependent district expected -> medium. HUMAN CHECK: an Orange PA millage-code table would settle composition.
