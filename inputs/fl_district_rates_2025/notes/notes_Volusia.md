- PA "Taxing Authority Code Description - 2025" sheet: one row per 3-digit millage code with all component levies and the 2025 final total; all 23 roll codes present (codes printed with leading zeros, e.g. 016).
- Components sum to the printed total for every row (asserted). Generic reader was wrong for 016 Deltona (18.7448, not 16.9077) and 201 Ormond Beach (16.3635, not 0.1573).
