# Collier 2025 district millage
- TACD is the PA TBL203 Millage Code Summary (64 pp): each millage code lists its authorities with FINAL rates and a total. I parsed all 314 codes; the components re-sum to the printed totals in every case.
- Roll codes have leading zeros (0058 = code 58). All 271 roll codes found. The generic reader only grabbed the first authority (3.0107), which is wrong.
- School 4.2490 = State Law 2.0010 + Local Board 2.2480. County general fund 3.0107 matches Table 1; Naples 1.23 and Marco 1.267 match.
- Totals range 9.05-18.34 mills. These are low but consistent with Collier's low county and school rates.
