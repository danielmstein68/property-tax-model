# Texas data requests for Daniel to send

Drafted 2026-10-20. These appraisal districts don't post bulk roll files; a Public Information Act
(PIA) request (Gov't Code ch. 552) gets them. Together they hold about 15% of Texas homesteads.
Send from your own email; ask for a cost estimate before any charge.

| District | Share of TX homesteads | Where to send | Notes |
|---|---|---|---|
| Bexar (BCAD) | 6.7% | OpenRecords@bcad.org (form: https://bcad.org/wp-content/uploads/2026/04/BCAD-Public-Information-Act-Request.pdf) | Their form says the appraisal export may be provided by FTP. |
| Denton (DCAD) | 3.4% | Their site's contact form (https://taxpayer.justappraised.com/c/denton_cad_tx/request-for-assistance), or check https://www.dentoncad.com in a normal browser for a "Data Extracts" page first | Older pages listed CSV/DBF extracts; the new site doesn't show them. |
| Montgomery (MCAD) | 2.6% | Check https://mcad-tx.org/appraisal-data-exports in a browser first (2025 file and layouts appear to be posted); otherwise a PIA request | A county copy says redistribution needs authorization; we don't redistribute rolls, only results. |
| Hidalgo | 2.3% | Hidalgo County Appraisal District, https://www.hidalgoad.org/ (public information officer) | No public download found. |
| Optional: Texas Comptroller | could cover all 254 districts | Property Tax Assistance Division, PIA request via https://comptroller.texas.gov/about/policies/public-information.php | Ask for all appraisal districts' 2026 EARS submissions (manual 96-1051). Unconfirmed whether they release them; if they do, it replaces most district-by-district work. |

## Draft request (adapt per district)

Subject: Public Information Act request: 2026 certified appraisal roll export

Dear Public Information Officer,

Under the Texas Public Information Act (Government Code ch. 552), I request a copy of the
[District]'s 2026 certified appraisal roll in electronic form: the standard appraisal data export
(for example the PACS / True Prodigy "Appraisal Export" layout, or your equivalent), including for
each property account the market, appraised and taxable values, homestead and other exemption codes
and amounts by taxing unit, state property category codes, year built, and over-65/disabled tax
ceiling (freeze) fields, together with the file layout and code tables. Information made
confidential by Tax Code s. 25.027 may be redacted.

Electronic delivery (FTP, file share or download link) is preferred. If there is a charge, please
send a cost estimate before processing the request.

The data will be used for nonpartisan research on the distribution of property taxes (Center for
Land Economics).

Thank you,
Daniel Stein
